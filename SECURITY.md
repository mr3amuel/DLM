# Security reporting

Use GitHub Private Vulnerability Reporting, once enabled, through this repository's
Security tab → Advisories → Report a vulnerability. Never post credentials, private
URLs, databases, browser pairing material or personal logs in public issues.

After creating the repository the owner must enable Settings → Security → Code
security → Private vulnerability reporting (GitHub may group this under Advanced
Security), and verify that Report a vulnerability is available. It is not assumed
to be enabled merely because this file exists. Until then do not send sensitive
reports through a public issue. No personal email address is published.
